# Changelog

## Next

### Added

- Structured `config/` and grouped plugin modules.
- Debugging with `nvim-dap`, DAP UI and virtual text.
- Diagnostics UI with Trouble.
- Linting through `nvim-lint`.
- Automatic tool installation through Mason Tool Installer.
- ToggleTerm and project-oriented CMake mappings.
- Expanded Tree-sitter language support.
- Dedicated health-check module.
- Windows installation instructions.

### Changed

- Removed the disabled Blink completion spec to keep one completion engine.
- Unified code-related mappings under `<leader>c`.
- Improved LSP root detection and diagnostics configuration.
- Updated the README and project positioning beyond C++ only.
